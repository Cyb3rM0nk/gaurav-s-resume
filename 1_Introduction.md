# About Gaurav

Fullname -> Gaurav Barotia

Gaurav Barotia is a Cyber Senior Assistant in the BAS team at BDO India, based in
Mumbai. He has more than 5 years of experience in performing
Vulnerability Assessment and Penetration Testing (VAPT) for web, mobile
applications and APIs across sectors such as insurance, finance, and e-
commerce. In these roles, he has supported clients in identifying security
weaknesses and strengthening their overall security posture. Gaurav
began his cybersecurity career with a six-month internship, where he
gained practical, hands-on exposure to web and API security testing. Over
the last 3 years, he has been working with BDO India’s Cyber BAS team,
primarily carrying out VAPT assessments to uncover vulnerabilities and
help safeguard organizational digital assets. During this time, he has
contributed to client engagements, executed technical assessments, and
supported secure implementation practices.
He began his career working in network configuration and NOC support,
where he gained hands-on experience in managing network
environments, troubleshooting issues, and ensuring smooth operational
performance. During this period, he also contributed to Vulnerability
Assessment and Configuration Audits (VA/CA), helping organizations
identify weaknesses and maintain security standards.
For the past 3 years, Gaurav has specialized in Web Application Security
Testing, API security testing, and Android application security
assessments. His work focuses on identifying vulnerabilities across
diverse platforms, analyzing security flaws, and providing actionable
recommendations to strengthen application security. With a combination
of technical expertise and practical testing experience, he consistently
helps clients enhance their security posture and protect critical digital
assets.
